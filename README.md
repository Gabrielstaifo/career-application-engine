# How It Works

```text
Current CV
    ↓
Review
    ↓
Feedback
    ↓
Rewrite
    ↓
Review Again
    ↓
Assignment Analysis
    ↓
Final Version
```

## 1. Review

Use `review.md` to evaluate your CV from the perspective of an experienced consultant buyer or hiring manager.

The review focuses on:

- First impression
- Relevance
- Credibility
- Commercial value
- Consultant positioning

---

## 2. Feedback

Use `feedback.md` to receive structured and actionable feedback.

The feedback highlights:

- Strengths
- Weaknesses
- Risks
- Missing information
- Areas for improvement

---

## 3. Rewrite

Use `rewrite.md` to transform the review findings into a stronger CV.

This step helps improve:

- Professional summary
- Assignment descriptions
- Skills presentation
- Client value communication

---

## 4. Analyze

Use `analyze.md` when applying for a specific role.

Compare:

- Assignment requirements
- Your CV

to identify:

- Match level
- Requirement gaps
- Recommended adaptations
```
